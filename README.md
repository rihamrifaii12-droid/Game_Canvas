## 📌 Description du jeu

Looney Chase est un jeu de poursuite inspiré de l’univers cartoon.

Le joueur choisit un personnage inspiré de Looney Tunes, puis doit survivre le plus longtemps possible en évitant des obstacles pendant qu’un ennemi le poursuit.

Le jeu est basé sur HTML5 Canvas et respecte les bonnes pratiques demandées dans le TP :
- Gestion d’états
- Architecture orientée objets
- Animation via requestAnimationFrame
- Transformations géométriques
- Gestion des collisions
- Système de niveaux
- High Scores sauvegardés

---

## 🎮 Gameplay

### Objectif
Survivre le plus longtemps possible.

### Fonctionnement
- Le joueur court automatiquement.
- Il doit éviter les obstacles.
- Un ennemi poursuit le joueur.
- Si le joueur touche trop d’obstacles ou est rattrapé → Game Over.

---

## 🎯 Fonctionnalités principales

- Menu interactif
- Sélection de personnage
- 3 niveaux de difficulté progressifs
- Système de score basé sur le temps
- Système de vies
- Game Over Screen
- High Scores sauvegardés localement
- Animation fluide 60 FPS
- Gestion d’états du jeu
- Transformations Canvas (translate, rotate, save, restore)
